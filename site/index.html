Angular Dojo VlV

Cada reto es una app de Angular ya rota. Tu trabajo es repararla, y npm run verify te dice si lo lograste.

Sin instalar nada: elige un reto y ábrelo en tu navegador.

Cómo funciona

  1. Abre un reto. El botón Abrir en Codespaces levanta VS Code en el navegador, ya en la rama del reto y con todo instalado (tarda un par de minutos la primera vez).
  2. Lee el brief y arregla. CHALLENGE.md se abre solo. Usa npm start para ver la app mientras trabajas.
  3. Verifica. Corre npm run verify en la terminal. ¿Atorado? npm run hint da una pista a la vez; npm run reset empieza de nuevo.

Necesitas una cuenta de GitHub. Codespaces incluye 60 horas al mes gratis; detén el codespace cuando termines. Si quieres guardar tu trabajo, Codespaces te ofrece hacer fork al primer commit. ¿Prefieres local? Clona el repo.

Reglas del dojo

  • No mires la solución antes de intentarlo.
  • No edites nada dentro de verify/: es lo que califica.
  • Las pistas se piden con npm run hint, no se buscan en el código.
  • El objetivo es entender el porqué, no solo poner verify en verde.
